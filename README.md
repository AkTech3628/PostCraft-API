# PostCraft-API
PostCraft API is a modular RESTful backend service designed for a blogging platform using Node.js, Express, and MongoDB. The project follows MVC architecture to ensure clean separation of concerns and scalable backend design. JWT-based authentication and custom middleware are used to secure protected routes and manage user access. MongoDB with Mongoose handles data persistence for users and blog content. All APIs are tested and validated using Postman to ensure correct request–response behavior. The project is currently configured to run locally and is structured to be deployment-ready.Middleware is implemented to manage authentication and control access to protected routes.
